# 机房运维试卷系统

面向机房运维团队的**单机版题库与自动组卷系统**：把散落在 Word / Excel / PDF / 文本里的运维试题导入题库，自动识别题型与选项，按配额组卷、配平分数、一键打印。

纯 Python 标准库实现（HTTP 服务 + SQLite），**零第三方依赖、零联网也能用**；可选接入 OpenAI 兼容接口，用于图片型 PDF 识别与答案审校。所有数据保存在本机文件。

## 功能

- **多格式导入**：`doc` / `xls` / `docx` / `xlsx` / 文字版 `pdf` / `txt` / `csv`，旧版 Office 二进制格式自带解析器，不依赖 Office 本体；图片型 PDF 与扫描件走视觉模型兜底
- **自动组卷**：系统自动 / 按分类配额 / 自定义组合三种模式，难度可按积分或占比控制，一键配平总分；试卷生成即快照，题库后续修改不影响历史卷
- **AI 审校**：缺答案的题推荐答案与解析，有答案的题复核对错；只出建议、逐题采纳，采纳错了可撤销
- **批量审校**：逐题提交，可暂停 / 继续 / 停止，从断点续跑
- **本地优先**：识别方式可选"只用本地规则"，全程零网络请求；密钥只存本机 `data/ai.json`，界面全程脱敏

## 运行

需要 Python 3.10+（无第三方包）。双击 `机房运维试卷系统/启动试卷系统.bat` 即可，自动挑端口并打开浏览器；或手动：

```bash
cd 机房运维试卷系统
python server.py
```

首次启动自动铺一份示例题库。停止双击 `停止试卷系统.bat`。
