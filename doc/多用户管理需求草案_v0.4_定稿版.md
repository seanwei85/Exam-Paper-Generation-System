# 多用户管理功能需求草案 v0.4（定稿版）
# 局域网 + 多账号岗位授权 + 分类级互斥 + 管理员被动只读

**状态**：定稿，待升版进需求书。**日期**：2026-11-02
**方向**：允许局域网访问；多账号按岗位（一级分类）授权，防误操作；同一分类同时只允许 1 个会话写，多人同时在线、各写各的分类、互不干扰。

---

## 1 目标（用户已确认·定型）

1. 局域网访问：不同工位同事都能登录使用。
2. 岗位授权防误操作：电气工程师只碰"电气"，其他人碰不到别人的分类。
3. 多人可同时在线、同时工作、互不干扰：靠"同一分类同时仅 1 会话可写"保证，永不写同一道题。

---

## 2 三条核心规则（用户已确认）

### 规则 1｜管理员转被动只读
- **有普通用户登录时**，管理员**可以登录、可以看**，但**不能写操作**（增/改/删题目、导入），**只能看 + 生成试卷**。
- 即：有普通用户在线时，管理员整体处于"只读 + 可组卷"状态，完全避开分类写冲突。
- 无普通用户在线时，管理员可正常写。

### 规则 2｜生成试卷的专业范围
- 普通用户：只能生成**自己专业分类**的试卷（电气工程师只能组电气卷）。
- 管理员：可生成**全专业**试卷。

### 规则 3｜生成试卷不算写占用
- "生成试卷"（组卷并保存）虽会写到 `paper`/`paper_item` 表，但**不占用分类互斥名额，也不被写互斥阻断**。
- 含义：管理员可以在普通用户写电气分类时，另一台电脑同时组卷；组卷不与题库编辑抢占。

**实现注记**：`paper_engine.build()` 会 `INSERT INTO paper` + `paper_item`。互斥只作用于"题库编辑"（增/改/删题、导入），组卷走独立通道，不参与分类占用检查。

---

## 3 核心机制：分类级互斥（题库编辑）

- **写操作**（仅限题库编辑）：新增/修改/删除题目、导入。发生在某个一级分类上。
- 读写分离：
  - **读**：多设备可并读，不限。
  - **写**：同一时刻，同一分类只允许 1 个登录会话在写。登录或首次写入某分类时占用该分类，再写同分类会被阻断。
- 效果：电气工程师在线编辑"电气"时，管理员（若允许写）可在另一台电脑同时编辑暖通/消防——只有同分类互相顶掉。

> 管理员在"有普通用户在线"时本就被规则 1 转为只读，所以管理员与普通用户的同分类写冲突被规则 1 使效率先规避；两个普通用户若被授权到同一分类，仍靠分类互斥兜底。

| 互斥维度 | 覆盖 | 复杂度 |
|---|---|---|
| 全局 1 人 | 所有人互斥 | 低 |
| **分类级（本方案）** | 同分类互斥、跨分类并行 | 低~中 |
| 题目级 | 同题互斥 | 中高（并发乐观锁） |

选用分类级：与岗位授权天然贴合，成本几乎等于全局互斥，却保留多人并行。

## 4 范围界定

### 4.1 做

| 能力 | 说明 |
|------|------|
| 局域网访问 | 可配置绑定 `0.0.0.0`；默认仍 `127.0.0.1` 本机 |
| 多账号 + 登录 + 会话 | 管理员建用户、登录、短会话、退出 |
| 岗位授权 | 每人授权到若干一级分类；管理员全量 |
| 分类级互斥写 | 同分类同时仅 1 会话可改题库，跨分类并行 |
| 接口层隔离 | 未授权分类在接口层拒绝（不只界面隐藏） |
| 管理员被动只读 | 有普通用户在线时管理员不能写题库，只能看 + 组卷 |
| 组卷专业范围 | 普通用户只组本专业卷；管理员组全专业卷 |

### 4.2 不做

- 不做题目级并发合并/乐观锁（被分类级互斥替代）。
- 不做精细按钮级/行级权限，粒度到一级分类。
- 不做复杂审计平台（可选留简单写痕迹，见 FR-MU-09）。
- 不做真正 HTTPS；局域网 HTTP 明文，内网可信环境可接受。
- 不做云/远程互联网访问。

## 6 安全与运维（局域网必要成本，已接受）

| 项 | 说明 |
|----|------|
| 暴露面 | 同网段任何设备都能打开登录页；登录是第一道安全关 |
| 密码传输 | HTTP 明文可被嗅探；内网可信环境可接受（用户已确认"做吧"） |
| 绑定默认关闭 | 默认 127.0.0.1；仅主动开启才绑 0.0.0.0，开启时醒目警示 |
| 防火墙 | 开局域网需放行端口 |
| 会话 | 短期过期 + SameSite/Origin 校验，防 CSRF/越权 |
| IP 变化 | 局域网 IP 变化时访问地址变，需提示绑定机当前 IP |

## 7 工作量与技术影响

- 服务器：绑定从 `127.0.0.1` 改可配置（`--host`/设置项），局域网开 `0.0.0.0`。
- 后端新增：`user`、`session`、`user_category`（授权）、写占用表（分类→会话）；登录/登出/用户管理/鉴权中间件；写入口加分类占用校验；管理员在线状态检查（有普通用户→只读）。
- 前端新增：登录页、用户管理页（建号+勾分类）、互斥/只读提示；题库页按授权只显示本岗位分类。
- 测试：权限隔离 + 分类互斥 + 管理员被动只读是重点；预计新增 35~55 项，存量用例补登录前置。
- 保持**零第三方依赖、纯标准库、单文件库**；`启动试卷系统.bat` 路由不变（默认本机）。

**互斥实现简单性**：一张 `{分类 → 占用会话}` 内存表 + 登录/写入口查询即可；会话过期/退出时释放。单进程内存，无需跨进程锁。
