# 机房运维试题库与自动组卷系统 产品需求文档

**版本**：V1.12（评审稿）
**日期**：2026-10-26
**形态**：本机运行（浏览器界面 + 本机数据库文件）
**适用**：机房运维岗位培训、月度考核、上岗认证的题库维护与试卷生成

---

## 1 文档说明

### 1.1 编写目的

本文档定义"机房运维试题库与自动组卷系统"的功能、规则与验收标准，作为开发实现与验收的依据。核心链路为：**维护结构化题库 → 设定题型题量与难度总分 → 系统自动抽题 → 输出带唯一编号的 A4 试卷与标准答案卷**。

### 1.2 术语

| 术语 | 说明 |
|------|------|
| 题库 | 全部题目的集合，按五大类与二级分类组织 |
| 题型 | 单项选择题、多项选择题、判断题、填空题、问答题 |
| 难度 | 易、中、难三档 |
| 难度积分 | 按题型与难度累加的整卷难度值，见 6.1 |
| 组卷 | 按题型题量与难度积分自动抽题生成试卷 |
| 试卷编号 | 系统生成时自动分配的唯一编号，见 6.4 |
| 快照 | 试卷生成时把题干、选项、答案完整复制进试卷明细，之后题库修改不影响已出试卷 |
| 草稿题 | 答案为空、可以入库编辑但不参与组卷的题目，见 FR-QE-09 |
| AI 建议 | AI 对某道题给出的标准答案、解析与判断依据。它是一份待确认的提案，采纳前题库不变，见 5.9 |

## 2 产品概述

### 2.1 背景

机房运维覆盖电气、暖通、弱电、消防、管理五大专业方向，考核出卷目前依赖人工挑题与手工排版，存在四个问题：题目散落在 Word/Excel 中无法统计；拼一套卷耗时数小时；不同批次试卷难度不一致；连续考核重复出题。

### 2.2 目标

| 目标 | 衡量标准 |
|------|----------|
| 出卷快 | 设定参数到拿到可打印试卷 ≤ 1 分钟 |
| 难度可控 | 整卷难度积分与设定值完全一致，误差为 0 |
| 结构一致 | 同一参数多次出卷，题型题量分值完全一致 |
| 数据不丢 | 断电、重启、清理浏览器数据后，题库与试卷完整保留 |
| 可追溯 | 每套试卷编号唯一，记录生成时间、组卷参数与抽题种子 |

### 2.3 本期范围

**做**：题库维护、单题录入、电子题库识别导入（含 AI 识别存量试卷）、自动组卷、试卷与答案卷输出、试卷台账、分类与规则配置、数据备份恢复。

**不做（后续版本）**：在线答题与自动阅卷、成绩分析、A/B 卷、移动端、多人协作与权限体系。

### 2.4 设计原则

1. 数据优先于界面：题目与试卷先落盘到本机数据库，界面只是读写入口。
2. 不静默凑数：抽题不满足硬性条件时拒绝出卷并说明缺口，不降级、不重复用题。
3. 试卷固化：生成即快照，题库后续改动不影响历史试卷。
4. 规则可配置：分类、积分规则、编号前缀、单位名称均在界面维护，不改代码。
5. 离线可用：无网络环境下全部功能正常。

## 3 用户与场景

### 3.1 角色

单机版不设权限体系，默认单一使用者（题库管理员兼考核管理员）。若后续需要多人，按 3.2 升级。

### 3.2 典型场景：月度考核出卷

1. 双击桌面图标启动系统，浏览器自动打开工作台。
2. 进入"自动组卷"，填写试卷标题、单位名称；系统带入默认 100 分模板：单选 25 题 × 1 分、多选 8 题 × 2 分、判断 15 题 × 1 分、填空 10 题 × 每空 1 分（按平均 2 空计 20 分）、问答 2 题 × 12 分，目标难度总分 40。
3. 系统实时校验：卷面总分 100，题量 60，难度积分上限 124，40 在可行区间内。
4. 点击"生成试卷"，1 秒内完成，显示编号 ZJLab-20261024-001、生成时间、易中难实际分布。
5. 预览卷面，确认后点"打印"输出 A4 试卷；切到"标准答案卷"另存为 PDF。
6. 试卷自动进入试卷库台账，可随时重新打开或重新打印。

## 4 数据模型

### 4.1 分类

两级结构，一级固定为五大类，可改名、可调序，不可删除（避免历史题目失去归属）；二级可自由增删改。

| 一级 | 二级默认 |
|------|----------|
| 电气 | 市电与配电、UPS、蓄电池、柴油发电机、防雷接地 |
| 暖通 | 精密空调、气流组织、温湿度、水系统、新风排风 |
| 弱电 | 综合布线、网络设备、动环监控、门禁、视频监控 |
| 消防 | 气体灭火、火灾报警、灭火器材、防火封堵、应急疏散 |
| 管理 | 巡检制度、变更与工单、应急预案、值班交接、安全规范 |

### 4.2 题目

| 字段 | 必填 | 说明 |
|------|------|------|
| 题目编码 | 自动 | 形如 Q-000123，系统生成，只读 |
| 一级分类 | 是 | 五大类之一 |
| 二级分类 | 是 | 该一级下二级项 |
| 题型 | 是 | 单选、多选、判断、填空、问答 |
| 难度 | 是 | 易、中、难 |
| 题干 | 是 | 纯文本，支持多行；填空题用 `____` 表示空位 |
| 选项 | 依题型 | 单选/多选 2~6 项；判断题固定"正确/错误"，不需录入选项 |
| 答案 | 否 | 单选：单个字母；多选：多个字母（如 ABD）；判断：正确/错误；填空：按空顺序给出答案，空之间用 `|` 分隔；问答：参考答案文本。**允许留空**，留空即"草稿"：可入库、可编辑，但不进入组卷池（见 FR-QE-09）。填写了就必须合法 |
| 空数 | 填空必填 | 题干空位个数，录入时自动统计 `____`，可手工修正；该题分值 = 空数 × 每空分值 |
| 建议分值 | 否 | 留空则按题型默认规则计分；填写后优先采用（用于个别高权重题） |
| 解析 | 否 | 显示在答案卷 |
| 标签 | 否 | 逗号分隔，用于检索 |
| 使用次数 | 自动 | 被抽中次数 |
| 最近使用 | 自动 | 最近一次出卷时间 |
| 创建/修改时间 | 自动 | — |

### 4.3 试卷

| 字段 | 说明 |
|------|------|
| 试卷编号 | 唯一，见 6.4 |
| 试卷标题 | 用户填写 |
| 单位名称 | 取系统设置，可单次覆盖 |
| 生成时间 | 精确到分钟 |
| 组卷参数 | 题型题量分值、目标难度总分、随机种子，整份保存 |
| 卷面总分 / 题量 / 难度积分 | 生成后回填 |
| 易/中/难 题数 | 按题型分别记录 |
| 试卷明细 | 题号、题目编码、题干快照、选项快照、答案快照、解析快照、分值、难度 |

### 4.4 其他

| 实体 | 说明 |
|------|------|
| 设置项 | 单位名称、编号前缀、默认考试时长、默认分值模板、备份保留份数 |
| 导入记录 | 文件名、导入时间、成功数、失败数、失败原因清单 |
| AI 审校建议 | 所属题目、类型（补全 / 复核）、结论（建议补全 / 一致 / 不一致 / 存疑）、建议答案、建议解析、判断依据、置信度、模型名、是否可采纳及原因、状态（待处理 / 已采纳 / 已忽略）、生成时间。一题只保留最新一条，重新审校即覆盖并回到待处理 |
| 备份记录 | 备份文件名、时间、大小 |

## 5 功能需求

### 5.1 工作台

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-HM-01 | 展示题库总量、五类题量占比、易/中/难分布 | P0 |
| FR-HM-02 | 展示最近 5 套试卷（编号、标题、时间、总分） | P0 |
| FR-HM-03 | 题库健康度提示：拿默认 100 分模板的题量需求，与现有**可出卷题量**逐题型核对，在工作台显示「题型 可用/需要（缺 N）」。可出卷题量不含草稿题（答案为空），并在同一区域单列一句「另有 N 道题缺答案，暂不参与组卷，到题库页可逐题补」。任一行不足时给红字结论并列出缺口，全部满足时给绿字「按默认模板题库够用，可以直接组卷」，不必等到点组卷才发现抽不满 | P1 |
| FR-HM-04 | 快捷入口：新增题目、导入题库、生成试卷 | P0 |

### 5.2 题库管理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-QB-01 | 列表展示：编码、题型、分类/二级、难度、题干摘要、使用次数、更新时间；缺答案的题在题干旁给「缺答案」标记（灰/琥珀色小徽标，不影响正常题） | P0 |
| FR-QB-02 | 筛选：关键词（题干/答案）、一级分类、二级分类、题型、难度、**答案状态（全部 / 只看缺答案 / 只看有答案）** | P0 |
| FR-QB-03 | 排序：最新录入、最早录入、最近修改、使用次数最多；分页，每页 20/50/100 可选 | P0 |
| FR-QB-04 | 编辑：进入表单修改，保存后更新修改时间 | P0 |
| FR-QB-05 | 删除：二次确认；已被试卷引用的题目允许删除，但历史试卷因有快照不受影响 | P0 |
| FR-QB-06 | 批量操作：勾选多题后批量改一级分类、批量改难度、批量删除。改一级分类时二级分类自动跟到该分类下的第一个二级，避免出现"电气 + 暖通某二级"这种不存在的组合；难度只接受易/中/难，分类必须存在，非法取值整批拒收并返回原因 | P1 |

### 5.9 AI 审校（补答案 / 复核答案）

题库里大量老题没有答案（厂商模板导出的面试题库整份没有答案列），人工逐条补不现实；同时已入库的答案也未必都经得起核对。这一节处理这两件事，**位置在入库之后的题库页，不在导入环节**：

- 导入的职责是忠实搬运（FR-IM-13 明确规定材料没给答案就留空），AI 顺手补答案会让"来自文件"与"模型生成"混在一起，日后无法追溯；
- 推理模型识别一页真实卷子要 200 秒上下，导入时再插一轮审校，批量导入时长直接翻倍；
- 缺答案的题本来就是草稿（FR-QE-09），不进组卷池，是个安全的待办清单，补到哪儿算哪儿不影响出卷。

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-AI-01 | **补答案与解析**：对答案为空或解析为空的题，由 AI 给出标准答案、解析与判断依据。题型格式按题干实际题型给：单选单个字母、多选连续字母、判断「正确/错误」、填空按空顺序用 `\|` 分隔、问答给分点要点。解析要讲原理或依据，不复述题干；依据记不清规范编号时只写原理，**不得编造条款号** | P1 |

## 6 关键规则

### 6.1 难度积分

| 题型 | 易 | 中 | 难 | 单题上限 |
|------|----|----|----|----------|
| 单项选择题 | 0 | 1 | 2 | 2 |
| 多项选择题 | 0 | 1 | 2 | 2 |
| 判断题 | 0 | 1 | 2 | 2 |
| 填空题 | 0 | 1 | 2 | 2 |
| 问答题 | 0 | 2 | 4 | 4 |

整卷难度积分 = 各题积分之和。某题型的积分上限 = 该题型题量 × 单题上限。

难度积分只由**题型与难度**决定，与分值无关：把某题从 1 分调到 5 分，难度积分不变。这样试卷难度与卷面分值两条线互不干扰。

### 6.2 默认组卷模板（100 分）

系统预置一套 100 分模板，进入组卷页自动带入，题量与分值可直接改。

| 题型 | 题量 | 分值规则 | 小计 | 难度积分上限 |
|------|------|----------|------|--------------|
| 单项选择题 | 25 | 每题 1 分 | 25 | 50 |
| 多项选择题 | 8 | 每题 2 分 | 16 | 16 |
| 判断题 | 15 | 每题 1 分 | 15 | 30 |
| 填空题 | 10 | 每空 1 分（按平均 2 空计） | 20 | 20 |
| 问答题 | 2 | 每题 12 分 | 24 | 8 |
| 合计 | 60 | — | 100 | 124 |

配套难度目标参考值 40，按易/中/难拆分为：单选 15/6/4、多选 3/3/2、判断 9/4/2、填空 5/3/2、问答 1/0/1。

填空题小计按平均 2 空估算，实际值在生成后按每题真实空数精确计算；若实际空数偏离，用"一键配平"把总分拉回 100 分。

考试时长默认 45 分钟，随模板保存；卷面标题行显示时长。

规则：卷面总分实时汇总显示；不等于 100 分时界面提示"当前 X 分，与标准 100 分不一致"，需勾选确认后才能生成（允许临时做 50 分等小卷）。

### 6.3 组卷规则

系统内置三种组卷方式。三者共用同一套抽题引擎，方式只是规则的预设组合，不是三套算法。

| 方式 | 抽题依据 | 默认开启的规则 |
|------|----------|----------------|
| 系统自动 | 题型题量 + 难度积分，五大类不限定数量 | 排除近期已用 |
| 按分类配额 | 在系统自动基础上，限定各分类题量 | 排除近期已用 + 分类配额 |
| 自定义组合 | 在配额基础上自由叠加附加规则 | 分类配额 + 用户勾选 |

#### 6.3.1 分类配额

配额填法（同一层级只用一种，避免混算）：

| 模式 | 填什么 | 校验 |
|------|--------|------|
| 按比例 | 各分类填百分数，如电气 30、暖通 25 | 合计必须为 100% |
| 按题数 | 各分类填题数，如电气 18、暖通 15 | 合计必须等于总题量 |

规则：

- **留空即均分**：不填的分类自动均分剩余量；全不填等于完全不限制
- **取整不漂移**：按比例换算后取整，用最大余数法补差，保证各分类题量之和精确等于总题量
- **二级下钻**：展开某一级后，在该一级题量内再分配；二级留空则该一级的题随机落到各二级
- **软约束**：分类配额允许 ±1 偏差，题型题量与难度积分是硬约束；生成后展示"配置配额 / 实际分布 / 偏差"

#### 6.3.2 难度控制的两种表达

| 表达 | 填什么 | 适用场景 |
|------|--------|----------|
| 积分目标（默认） | 整卷难度积分，如 40 | 沿用既有规则，各套卷难度可比 |
| 易中难占比 | 如 50 : 30 : 20 | 更直观，先定比例再倒推积分 |

- 两者是同一件事的两种算法，**只保留一个真值**：切换时自动换算，界面始终同时显示换算结果
- **不允许同时强约束**：既指定积分又指定比例，多数组合无解，系统拒绝并说明冲突项

#### 6.3.3 附加规则

| 规则 | 参数 | 默认 | 说明 |
|------|------|------|------|
| 排除近期已用 | 最近 N 套（1~10） | 开启，N=3 | 排除这 N 套卷出现过的题；N=0 表示不排除 |
| 必考锁定 | 题目 ID 列表 | 关闭 | 锁定的题必进卷并占用对应题型题量；超出该题型题量则拒绝生成 |
| 标签与批次范围 | 标签关键词、新题天数、新题占比 | 关闭 | 只从含指定标签的题中抽；可要求最近 N 天内录入的题占比不低于 X% |
| 换一题 | — | 下一期 | 生成后单题替换，保持题型、难度、分值、分类不变 |
| 历史卷派生 | — | 下一期 | 以上次卷为底换掉 N 题生成新卷，适合同岗位分批考 |

#### 6.3.4 约束优先级与冲突处理

1. 硬约束：题型题量、难度分解、必考锁定、范围过滤
2. 软约束：分类配额（±1）
3. 违反硬约束 → 不出卷，输出缺口报告
4. 违反软约束 → 允许出卷，台账标注偏差，不静默忽略
5. 多条规则叠加无解时，在预检阶段拦下并逐条列出冲突项（如"锁定 3 道问答题，但问答题题量只设了 2"），不进入抽题

#### 6.3.5 抽题流程

1. **预检**：逐题型统计可用题量、算难度可行区间、校验配额合计与锁定题，任一项不通过直接返回缺口
2. **分解难度**：按目标积分或占比求解各题型的易/中/难题数；多解时取与目标占比最接近的一组
3. **换算配额**：把比例或题数换算成各分类题量，取整补差
4. **锁定占位**：必考题先入卷，占用其所属题型的难度余量
5. **分组抽取**：按题型 → 难度 → 分类顺序抽题；分类按"已抽数 / 配额"比值最小者优先，使实际分布逼近配额
6. **复核**：核对题量、分值、难度积分、锁定题是否都在卷内；不通过则重抽，最多 20 次
7. **落盘**：保存快照、组卷参数与随机种子，生成试卷编号

### 6.4 试卷编号

- 格式：`前缀-YYYYMMDD-序号`，如 `ZJLab-20261024-001`
- 序号按天重置，三位补零；当天超过 999 套自动扩位
- 唯一性由数据库唯一约束保证，重复时自动顺延，不出现重号
- 卷面右上角显示编号与生成时间；台账、答案卷同样显示

### 6.5 缺题处理

| 场景 | 系统行为 |
|------|----------|
| 某题型可用题量 < 需求题量 | 拒绝生成，提示"单项选择题需 40 题，当前可用 32 题，缺 8 题" |
| 目标难度积分超出可行区间 | 拒绝生成，显示可行区间与当前值 |
| 某难度题量不足 | 拒绝生成，缺口报告精确到"题型 × 分类 × 难度 × 缺几题" |
| 分类配额合计不等于 100% 或总题量 | 拒绝生成，提示当前合计与差额 |
| 锁定题数量超过所属题型题量 | 拒绝生成，指出题型与超出数量 |
| 题库在生成过程中被修改 | 生成为单次事务，结果不受影响 |

**禁止**：自动降低题量、自动放宽难度、重复使用同一题、静默跳过。

## 7 技术形态与数据存储

### 7.1 形态

浏览器界面 + 本机小服务，数据保存在本机数据库文件。启动方式为双击图标，浏览器自动打开；关闭浏览器不影响数据，再次启动继续使用。

| 对比项 | 本方案 | 纯浏览器方案（已否决） |
|--------|--------|------------------------|
| 数据位置 | 本机 SQLite 文件，可直接复制备份 | 浏览器存储，清缓存即丢 |
| 容量 | 10 万题 + 数千套卷无压力 | 约 3000~5000 题即到上限 |
| 重启电脑 | 数据完整保留 | 依赖浏览器策略，存在风险 |
| 安装 | 双击启动图标，无需安装 | 双击 HTML |

### 7.2 文件布局

| 路径 | 作用 |
|------|------|
| `机房运维试卷系统/启动试卷系统.bat` | 启动入口（双击） |
| `机房运维试卷系统/server.py` | 本地服务与接口 |
| `机房运维试卷系统/ui.html` | 界面 |
| `机房运维试卷系统/data/library.db` | 数据库（含全部题目与试卷） |
| `机房运维试卷系统/data/backup/` | 自动备份（默认保留 30 份） |

### 7.3 数据可靠性

1. 每次写操作使用数据库事务，成功才返回，失败明确报错。
2. 写库前先校验，杜绝"界面显示成功、实际未保存"。
3. 每日首次启动自动备份一份，保留最近 30 份；备份失败在界面醒目提示。
4. 设置页可手动备份到自选目录（如 U 盘、网盘同步目录），并显示数据文件路径。
5. 数据库文件可整体复制到另一台电脑直接使用。

## 8 非功能需求

| 类别 | 指标 |
|------|------|

| 安全 | 服务仅监听本机 127.0.0.1，不对外开放；数据不出本机 |

## 10 验收标准

| 编号 | 验收项 | 通过标准 |
|------|--------|----------|
| AC-01 | 单题录入 | 五种题型均可录入并保存，校验规则生效，非法输入无法保存 |
| AC-02 | 数据持久 | 关闭浏览器、重启电脑后重新启动，题库与试卷数量、内容完全一致 |
| AC-03 | 分类维护 | 二级分类增删改后，题库筛选与录入同步生效 |
| AC-04 | Excel 导入 | 100 题标准模板导入，识别正确率 100%，错误行有原因说明 |
| AC-05 | Word/PDF 导入 | 25 题混合格式文档，题型、难度、答案识别正确，结果可人工修订；文字型 PDF 逐行还原（页序按 `/Kids`、换行按纵坐标），扫描件明确提示"没有文字层、请导出图片" |
| AC-05a | 存量试卷批量迁移 | 一份格式不统一、无题号的旧卷子（Word/PDF/图片），选"自动"识别方式后能拆出可入库的题目；界面标注这批题是 AI 认的还是本地规则拆的，AI 认的提示逐条核对 |
| AC-05b | 不联网可用 | 选"只用本地规则"时导入全程零网络请求（抓包为 0），规整格式仍能正常拆题 |
| AC-05c | 密钥不外泄 | AI 密钥只存在于本机 `data/ai.json`；界面密钥框为密码类型且不回填，页面 DOM、接口返回、日志、连通测试结果中均不出现完整密钥 |
| AC-06 | 组卷正确性 | 连续生成 10 套，每套题量、分值、总分与设定完全一致 |
| AC-07 | 难度积分 | 每套试卷难度积分与目标值误差为 0 |
| AC-08 | 编号唯一 | 连续生成 20 套，编号连续且互不重复，卷面显示编号与时间 |
| AC-09 | 答案卷 | 每题均有答案，问答题有参考答案，题号与试卷一致 |
| AC-10 | 缺题处理 | 人为制造题量不足，系统拒绝出卷并给出精确缺口，不得凑数 |
| AC-11 | 快照隔离 | 生成试卷后修改或删除原题，重新打开该试卷内容不变 |
| AC-12 | 打印排版 | A4 输出无跨页断题，页码正确，密封线与信息栏完整 |
| AC-13 | 备份恢复 | 备份后清空数据再恢复，题目与试卷完整回来 |
| AC-14 | 性能 | 1 万题规模下组卷 ≤ 2 秒，列表操作无明显卡顿 |
| AC-15 | 填空题计分 | 2 空题按每空 1 分计 2 分，空数可手改，答案与空顺序一一对应 |
| AC-16 | 单题自定义分值 | 生成后逐题改分立即生效，总分实时重算；一键配平后可精确等于 100 分 |
| AC-17 | AI 补答案 | 勾选 60 道缺答案的题批量审校，每题得到建议答案、解析与依据；采纳前题库答案仍为空，采纳后答案进库且该题从草稿转为可组卷 |
| AC-18 | AI 建议边界 | AI 给出不在选项范围内的答案、或填空答案个数与空位不符时，该建议标记为不可采纳，界面采纳按钮置灰、接口层同样拒绝，题目不被改动 |
| AC-19 | AI 复核 | 已有答案的题复核后，结论为「不一致 / 存疑」的能被一个筛选项全部筛出；对判「一致」的题点采纳不改动任何字段 |
