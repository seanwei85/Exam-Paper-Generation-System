# 机房运维试卷系统 使用说明

**版本**：V1.2
**日期**：2026-10-25
**适用**：本机单机运行，数据全部保存在本机文件

---

## 1 启动与关闭

| 操作 | 方法 |
|------|------|
| 启动 | 双击 `机房运维试卷系统\启动试卷系统.bat`，浏览器自动打开 |
| 关闭 | 关掉弹出的黑色命令行窗口，或直接关浏览器（数据已实时保存） |
| 访问地址 | `http://127.0.0.1:8765`（端口被占用时自动顺延） |

首次启动会自动建库、建五大分类、写入 35 道示例题，并每天自动备份一次。

---

## 2 七个模块

| 模块 | 用途 | 关键操作 |
|------|------|----------|
| 工作台 | 看题量、分类分布、难度分布、最近试卷 | 题量不足时按提示补题；「题库健康度」直接告诉你够不够出默认卷 |
| 题库管理 | 查题、筛题、改题、删题、导出 | 按分类/二级/题型/难度/关键词筛选；勾选后可批量改分类、改难度、删除；可按当前筛选导出 Excel；点题干可先预览 |
| 单题录入 | 手工录一道题 | 填空自动数空位，分值=空数×每空分值 |
| 批量导入 | 从 Excel/Word/PDF/图片/文本导入 | 选识别方式→拖入文件→核对识别结果→确认入库 |
| 自动组卷 | 生成试卷 | 选方式→填题量→看预检→生成 |
| 试卷库 | 历史试卷 | 查看、打印、删除 |
| 系统设置 | 单位信息、分类、备份 | 改卷头单位、增删分类、备份恢复 |

**工作台的「题库健康度」**会拿默认 100 分模板的题量需求，跟你的题库逐题型对一遍，显示成「单项选择题 48/25」这样。
有一项不够就红字提示还缺多少，全部够就是绿字「按默认模板题库够用，可以直接组卷」——不用等点了组卷才发现抽不满。

## 3 录题要点

### 3.1 五种题型

| 题型 | 难度积分 | 说明 |
|------|----------|------|
| 单项选择题 | 易0 / 中1 / 难2 | 答案只能是 1 个选项 |
| 多项选择题 | 易0 / 中1 / 难2 | 答案至少 2 个选项 |
| 判断题 | 易0 / 中1 / 难2 | 答案只能填「正确」或「错误」 |
| 填空题 | 易0 / 中1 / 难2 | 题干用连续下划线表示空位，如 `18~____℃` |
| 问答题 | 易0 / 中2 / 难4 | 答案填参考要点，阅卷时对照 |

### 3.2 填空按空计分

题干里出现几处 `____` 就自动算几个空。本题分值 = 空数 × 每空分值（默认 1 分/空）。
多空答案按顺序用竖线分隔，例如 `27|60`，答案卷会逐空显示。

### 3.3 建议分值

个别题权重高时，可单独填「建议分值」，优先于题型默认分值。留空则按题型默认。

### 3.4 选项顺序

单选/多选录入后，选项可以：

- **拖动**最左边的把手换位置；
- 或者点该行的 **↑ / ↓** 按钮上下挪一格（不方便拖动时用这个）。

换完位置，选项标号 A/B/C/D 会自动重排，答案跟着标号走，不用手工改。

### 3.5 保存前查重

点「保存」时，系统会拿这道题的题干跟库里已有的题比一遍（全角半角、空格、括号占位、下划线都不算差别）。
相似度很高时**不会直接存**，而是弹窗告诉你库里那道题的原文和相似程度，你可以：

- 点「仍然保存」照常入库（同一考点换个问法的情况很常见）；
- 或者点「取消」回去改题干。

题干太短（归一化后不足 6 个字）不参与比对，避免「压力」和「压力表」这类短词互相误判。

### 3.6 题库页的批量与导出

- **批量改分类**：勾选多题 → 点「批量」→ 选一级分类，二级会自动落到该分类下的第一个二级，不会出现「电气 + 暖通某二级」这种不存在的组合。
- **批量改难度**：同上，只接受易/中/难。
- **导出 Excel**：先筛好（关键词、分类、二级、题型、难度），再点「导出」，导出的就是当前筛选结果，列顺序与导入模板一致，改完可以直接导回去。文件名带日期，例如 `题库导出_20261025.xlsx`。

## 4 批量导入

### 4.1 支持格式

| 格式 | 支持 | 说明 |
|------|------|------|
| .xlsx / .csv | 支持 | 一行一题，列可以是「题干 / A / B / C / D / 答案」；换列顺序也不影响 |
| .docx | 支持 | 按段落识别 |
| .doc | 支持 | 老版 Word 直接读，不用先另存；目录域代码会自动剔掉，不会混进题干 |
| .xls | 支持 | 老版 Excel 直接读，多张工作表会依次读，重复表头自动去掉 |
| .txt | 支持 | 纯文本题库 |
| .htm / .html 表格 | 支持 | 有些系统「导出 Excel」其实是网页表格，扩展名却写成 .xls，这种也能读 |
| RTF | 支持 | 从别的系统导出的富文本 |
| .pdf（文字版） | 支持 | Word / WPS 导出的、能选中文字的都能读；逐行还原，题目不会被并成一坨 |
| .pdf（扫描件） | 支持，但不是本地读 | 里面是图片、没有文字层，要交给 AI 看图；或把每页导出成 PNG/JPG 再导 |
| .png / .jpg / .jpeg / .webp | 支持，需开 AI | 手机拍的卷子、屏幕截图都行；画面端正、光线均匀识别率最高 |
| .bmp / .gif / .tif / .heic | 不支持 | 多数模型不认，请先转成 PNG 或 JPG |

> 扩展名不作数，按文件内容判断。改了后缀的「假 .doc」「假 .xls」，系统会直接说清它实际是什么（比如"这其实是 xlsx，把后缀改回 .xlsx 就行"），不会抛一堆看不懂的错。

> 为什么 PDF 以前不支持、现在能了：文字版 PDF 现在由系统自己解析（页序按 PDF 的页面树、换行按文字坐标判断），不联网也能读；只有"整页都是图片"的扫描件才需要 AI。

### 4.2 识别方式：先选走哪条路

导入页有一排按钮，三档：

| 档位 | 怎么走 | 什么时候选 |
|------|--------|------------|
| 自动（推荐） | 先用本地规则拆；拆不出来才调 AI | 默认就选它。规整的文件不花一分钱，乱版式自动交给 AI |
| 只用 AI | 整份材料直接给模型 | 手上这份卷子版式特别乱，或者你确信规则的书写习惯对不上 |
| 只用本地规则 | 全程不联网，一次请求都不发 | 题库内容不能外传；或有保密要求 |

选了哪档会被记住，下次打开还是它。

> 「只用本地规则」时系统确实一个网络包都不发，这一点有专门的测试盯着。代价是图片和扫描件读不出来——它们没有文字层，本地规则无从下手。

### 4.3 第一次用 AI：先去设置里填三样东西

「系统设置 → AI 识别」：

| 字段 | 填什么 | 例子 |
|------|--------|------|
| 接口地址 | 兼容 OpenAI 格式的地址，末尾带 `/v1` | `https://api.deepseek.com/v1` |
| 密钥 | 服务商给的那串 sk- 开头的密钥 | `sk-…` |
| 文本模型 | 用来读文字材料的模型名 | `deepseek-chat` |
| 视觉模型 | 可选。读图片要用它；留空则用文本模型 | `qwen-vl-max` |

填完点「保存」，再点「测试连通」——通了会显示"连通正常，模型：xxx"，不通会把对方给的原文照抄出来（比如 `Invalid API key`），照着改就行。

几点说明：

- 密钥只存在本机 `data/ai.json`，不写进数据库、不进日志。
- 页面上只显示末 4 位（`****wxyz`），密钥框是密码框、且不回填——别人翻你的页面源码也拿不到完整密钥。
- 只改模型名时，密钥框留空就行，不会把已存的密钥抹掉。真要清掉，点「清除密钥」。

### 4.4 识别规则

系统按下面的书写习惯拆题，符合即可高准确率导入：

```
一、单项选择题
1. 机房精密空调的加湿用水应使用（　）。
A. 自来水
B. 软化水
C. 海水
D. 中水
答案：B
解析：自来水硬度高，易在加湿罐结垢。

2. 【难】UPS 电池组的后备时间取决于（　）。
A. 负载大小
B. 机房面积
答案：A
```

| 识别项 | 依据 |
|--------|------|
| 题型 | 「一、单项选择题」这类大题标题 |
| 题目 | 行首的 `1.` `2、` `（3）` |
| 选项 | 行首的 `A.` `B、` `(C)` |
| 答案 | `答案：` `正确答案：` `【答案】` |
| 解析 | `解析：` `【解析】` |
| 难度 | 题干前的 `【易】【中】【难】`，未标默认中等 |
| 分类 | 题干中出现电气/暖通/弱电/消防/管理时自动归类 |

识别结果会先在表格里列出来，**每题都可以改题型、难度、分类、答案，也可以取消勾选**，确认后才入库。

### 4.5 先看看识别效果

不想准备文件也想确认系统能不能认自己单位的题库，点页面上的「载入示例看看效果」，会直接灌入一份含五种题型、带【难】标记、含多空填空的示例文本并走完整解析流程。看这张表就知道识别规则合不合自己的书写习惯，再决定要不要改题库格式。

### 4.6 核对这张表

识别结果是一张可编辑的表，入库前所有内容都能改：

| 列 | 能做什么 |
|----|----------|
| 勾选 | 不想入库的题取消勾选即可 |
| 题型 | 五种题型下拉切换 |
| 题干 | 直接改文字 |
| 选项 | 只显示选项个数，判断题/填空题/问答题显示 `-` |
| 答案 | 直接改；填空题多个空用竖线分隔（如 `27|60`），入库时按空拆开 |
| 难度 | 易 / 中 / 难 |
| 分类 | 五大类，改完二级分类会自动切到该类的第一个 |
| 二级分类 | 在所选一级分类下选择 |
| 删除 | 这一行整题不要了，点 × 移除，后面的勾选状态自动跟着上移 |

三个细节：

- **缺答案的行会标黄**（答案框变红、左侧一条红杠，框里提示"缺答案"），表头同时显示"N 题缺答案（可先入库再补）"。这份题库确实没有答案列（很多厂商模板就是），可以直接入库——会存成**草稿**，能编辑补答案，但不参与组卷；要点确认框放行。缺**题干**的才真的会被拦下，并告诉你是第几题。
- 万一提交时被后端拒收，**页面不会弹窗打断你**，而是在表格上方列出每题的具体原因，并把这几题自动取消勾选，改完再点一次即可。
- 顶部「批量设置分类」可以一次性把勾选的题都改成同一个分类。

### 4.7 重复题会被自动标出来

导入前系统会拿每道题跟库里**全部已有题目的题干**比一遍，不管什么题型都参与比。相似度到 0.90 就算重复，表现是：

- 该行题干左边出现黄色的「疑重复」小标签，**鼠标停在标签上**会告诉你库里那道题的原文和相似度；
- 该行**默认不勾选**，表头同时显示「N 题与题库疑似重复，默认未勾选」。

比对前会先做归一化：全角转半角、去掉空格、去掉括号占位和下划线。所以「（　）」和「( )」算同一道题，从别处复制粘贴带来的格式差异不会让它漏判。

判重只是提醒，不是禁止。确认这题确实要再存一份（比如同一个知识点要求两种问法），点「全选」再入库就行。

### 4.8 导入记录在哪看

导入页下方「最近导入」列着最近 6 次入库：时间、文件名、共几题、成功几题、失败几题。只要这次点了确认入库且有题目，就会留一条——包括全部失败的情况，方便回头查"上次到底导进去多少"。没导过时这里显示"暂无导入记录"。

记录存在本机数据库里，关掉程序再打开还在。

### 4.9 用 Excel 模板最省事

点「下载 Excel 模板」拿到一份表头已经写好的 xlsx，照着填最不容易出错。表头这一行不要改名、不要删，数据从第二行开始往下写。

| 列名 | 必填 | 说明 |
|------|------|------|
| 题型 | 否 | 单选题 / 多选题 / 判断题 / 填空题 / 问答题；不填则按选项和答案自动推断 |
| 分类 | 否 | 电气 / 暖通 / 弱电 / 消防 / 管理；不填则按题干关键词归类 |
| 二级分类 | 否 | 填了会一起带上；需与系统设置里该分类下的二级名称对上 |
| 难度 | 否 | 易 / 中 / 难；不填按中等 |
| 题干 | 是 | 填空处用 `____`（连续下划线） |
| A~D | 否 | 选择题的四个选项，只写内容不写"A." |
| 答案 | 是 | 单选写 `B`；多选写 `ABD`；判断写 `正确`/`错误`；填空多空用竖线 `27|60` |
| 解析 | 否 | 阅卷参考，不进卷面 |

两个要点：

- **列的顺序随便排**，夹了无关列（比如"备注""出题人"）也不影响，系统按列名找。
- 少了「题型」列也没关系，只要 A~D 里有内容和答案，就能认出是选择题。

> 模板里自带的五行示例不是摆设：系统保证模板能被自己原样读回。也就是说你填完直接导回来，识别结果和模板里写的一致。

### 4.10 手上已有一堆格式不一的卷子，怎么搬最快

不用先统一格式。按这个顺序走，改的量最少：

1. **先拿一份最典型的旧卷子，用「自动」档直接导。** 结果表出来先看顶部那行说明：
   - 写「按本地规则拆出来的」→ 说明这份材料本来就规整，直接核对入库即可，没花钱。
   - 写「AI 识别出来的」→ 规则的盲区，已经让模型上了，重点看题干和答案有没有认错字。
   - 写「部分块由 AI 识别、部分块按本地规则拆出」→ 材料很长被分成几块处理，核对时优先看 AI 认的那部分。
2. **拆得不对再换档，别改文件。** 手写体、盖章、拍照倾斜 → 选「只用 AI」，最好在设置里配一个视觉模型；如果是文字材料但版式特别怪，也选「只用 AI」。
3. **有块识别失败会明说。** 结果区会列出「第 N 块没能识别出来（接口报错或超时）」，把那一块内容单独存成一个小文件重导一次就行，不用整份重来。
4. **PDF 先看是哪种。** 打开能拖选文字 → 文字版，直接导；拖不动、只能整页选中 → 扫描件，把每页另存成 PNG 再导。
5. **导完再补分类。** 一级分类能按题干关键词自动归，二级分类通常识别不出来，入库后在题库页勾选同一批题、用「批量设置分类」一次改完，比在结果表里一行行改快得多。
6. **页脚不用管。** 「第 N 页 共 M 页」这类页码会被自动忽略，不会拼进题干或选项里——题目跨页时页脚正好卡在选项中间，系统会在拆题前整行删掉。

> 重复题不用自己排：跟题库里已有题目高度相似的会被标「疑重复」并默认不勾选，一眼就能看出哪些是重复搬进来的。

### 4.11 没有答案的题库也能先收进来（草稿）

有些存量题库是口试/面试用的（开关电源、油机、蓄电池、高低配、UPS 那几批最常见），**整份没有答案列**，答案在带班的老师傅脑子里。这类文件不用等答案补齐再导：

1. 直接导入，结果表会把每道缺答案的题标黄，顶部写「N 题缺答案（可先入库再补）」；
2. 点入库会问一次"将先入库为缺答案草稿"，确认即入；
3. 这些题记为**草稿**：能在题库页正常查看和编辑，但**不会**被抽进试卷——卷子要附标准答案，抽到空答案等于出一份没法评分的卷；
4. 补答案：题库页把「答案状态」切到「只看缺答案」，逐题填完保存，这一题就自动进入组卷池，不用再做别的动作；
5. 工作台的健康度也只算"有答案的题"，所以一堆草稿不会让它误报"题量够用"。

> 一句话区分：**缺答案**可以入库（草稿），**缺题干**不行（那不叫题）。答案是"填错"的同样不行——放行的是空白，不是错误。

## 5 组卷

### 5.1 三种方式

| 方式 | 抽题依据 |
|------|----------|
| 系统自动 | 只按题型题量与难度积分，五大类不限量 |
| 按分类配额 | 一级分类按比例或题数分配，二级在该一级内再分 |
| 自定义组合 | 在配额基础上叠加排除、锁定、标签范围 |

### 5.2 难度两种填法

- **难度积分**：直接填整卷积分（如 40），系统拆到各题型
- **易中难占比**：填 50 / 30 / 20，系统反算积分

两者只能用一个，切换时会自动换算，不会互相打架。

**难度积分留空时**，系统按「中等偏易」给一个推荐值（各题型积分上限之和的 30%），预检面板会写明「当前用的是推荐值」。
如果想要全易卷，明确填 `0` 即可——填了 0 就按 0 走，不会被推荐值顶掉。

### 5.3 附加规则

| 规则 | 作用 |
|------|------|
| 排除近期已用 | 近 N 套卷出过的题不再抽，默认 3 套 |
| 必考锁定 | 指定题目必进卷，占用该题型题量 |
| 标签与批次范围 | 只抽含指定标签的题，可要求新题占比 |

### 5.4 预检

右侧面板实时显示：题量、卷面总分、难度积分与可达区间、分类配额、错误与提示。
**预检不通过不会出卷**，会明确告诉你缺什么：

- 题库题量不足 → 缺哪个题型、缺几题
- 难度构成凑不出 → 需要几题、库里易/中/难各有多少
- 难度积分超范围 → 可达区间是多少
- 锁定题超过题量 → 哪个题型超了

题库不够时，可点「按题库可用量自动调整题量」一键降配。

### 5.5 生成后

- 自动编号：`ZJLab-20261024-001`（前缀+日期+当日流水，唯一）
- 保存快照：题库后续改动不影响已出的卷
- 卷面显示编号与生成时间
- 用配额方式组卷时，详情页会多一张「配额执行」表：每个分类配置几题、实际抽到几题、差多少。
  差值超过 1 题的会整行标出来；差 1 题是取整的正常波动，不算问题。
  如果某类偏差很大，通常是那一类的题不够——照着「题库健康度」去补题即可。

## 8 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 双击 bat 没反应 | 电脑没装 Python。安装 Python 3.9+ 后重试，或用管理员权限运行 |
| 浏览器打开是空白 | 等 2 秒刷新；若仍空白，看命令行窗口是否报错 |
| 预检提示题量不足 | 题库题量或难度分布不够，按提示补题，或点「自动调整题量」 |
| 总分不是 100 | 填空题按实际空数计分，与预估有差异；用「一键配平」修正 |
| 连续出卷时提示缺题 | 「排除近期已用」生效了，可把套数改小或关掉 |
| 导入识别不准 | 按第 4.4 节的书写习惯整理后重导，或在预览表里直接改；版式特别乱就按 4.2 换成「只用 AI」 |
| 传图片提示"需要先开启 AI" | 图片没有文字层，本地规则读不了。到「系统设置 → AI 识别」填地址、密钥、模型后重试（见 4.3） |
| 测试连通报 `Invalid API key` | 密钥填错了或已失效，重新复制一次；注意别带多余空格 |
| 测试连通报 404 / Not Found | 接口地址少了或多了 `/v1`，改成 `https://…/v1` 这种形式 |
| AI 识别报"模型不支持图片" | 当前模型不是多模态的，在设置的「视觉模型」里换一个能看图的（如 `qwen-vl-max`） |
| 扫描件 PDF 提示读不出 | 里面是整页图片。把每页另存为 PNG/JPG 再导，或在设置里配好视觉模型后直接传图片 |
| 导入很慢 | 材料长会被分成多块逐块请求，等进度走完即可；只想快就别选「只用 AI」，用默认的「自动」 |
| 导入了但组卷时说题不够 | 先看题库页「答案状态 → 只看缺答案」有没有一堆草稿题；草稿不参与组卷，补上答案即可（见 4.11） |
| 提示"这个文件不是 Word/Excel 文档" | 后缀被改过（常见于网页另存的 .xls）。按提示把它改回真实后缀再导，不要重新排版 |
| 不想让题库出网 | 识别方式选「只用本地规则」，全程零网络请求；代价是图片和扫描件读不出来 |
| 端口被占用 | 系统会自动换到 8766 等端口，看启动窗口提示的地址 |

## 9 验收自测清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 双击启动 | 浏览器自动打开，工作台显示题量 |
| 2 | 录入五种题型 | 都能保存，非法答案被拦截并提示原因 |
| 3 | 填空题 | 自动识别空数，分值=空数×每空分值 |
| 4 | 批量导入 | 拖入示例文档能识别出题，预览可改 |
| 4a | 载入示例 | 点「载入示例看看效果」能列出 6 道题，无残留加载提示 |
| 4b | 下载模板 | 下载的 xlsx 能打开，原样导回识别出 5 道题 |
| 4c | 缺答案标黄 | 清空某题答案后该行标黄、表头显示"N 题缺答案（可先入库再补）"；确认后能入成草稿 |
| 4c2 | 缺答案不参与组卷 | 库里只有草稿题时组卷提示题量不足；补上答案后同一题能抽进卷子 |
| 4c3 | 缺题干被拦下 | 清空题干后点入库，明确告诉你"第几题缺题干"，题目留在表里 |
| 4d | 删除整行 | 点 × 移除一题后行数与勾选数同步减少，其余行顺序不错乱 |
| 4e | 重复题提示 | 库里先存一道题，再导同一道：该行标「疑重复」且默认不勾选，点全选后仍能导入 |
| 4f | 导入记录 | 入库后导入页「最近导入」出现一条记录，文件名与成功/失败题数相符 |
| 4g | PDF 导入（文字版） | 把一份 Word 卷子另存为 PDF 后导入，能逐行拆出题目，题干与选项不粘连 |
| 4h | PDF 导入（扫描件） | 传一份扫描版 PDF，提示"没有文字层、请导出成图片"，而不是笼统报"不支持" |
| 4i | 图片识别 | 配置好 AI 后传一张卷子截图，能拆出题目；结果区顶部说明这是 AI 识别的 |
| 4j | 识别方式 | 三个档位能切换、切换后被记住；选「只用本地规则」时提示明确写"不会发出任何网络请求" |
| 4k | 密钥不外泄 | 页面源码、接口返回、测试连通结果里都搜不到完整密钥，密钥框不回填 |
| 4l | 老版 Word/Excel | 直接拖入 `.doc` / `.xls` 能识别出题；改成别的后缀的假文件会明确说明它实际是什么格式 |
| 5 | 组卷-系统自动 | 生成后题型题量与设置完全一致 |
| 6 | 组卷-难度积分 | 生成后难度积分等于目标值 |
| 7 | 组卷-分类配额 | 各类题量与配额偏差不超过 1 题 |
| 8 | 排除近期已用 | 连续两套无重复题目 |
| 9 | 必考锁定 | 锁定题必在卷内 |
| 10 | 编号 | 格式 ZJLab-日期-序号，连续不重号 |
| 11 | 卷面 | A4 打印完整，题目不跨页拆开 |
| 12 | 答案卷 | 逐题有答案，填空按空显示 |
| 13 | 快照 | 改题库后，已生成试卷内容不变 |
| 14 | 配平 | 一键配平后总分精确等于 100 |
| 15 | 重启 | 关闭再启动，题库与试卷都在 |
| 16 | 备份恢复 | 恢复后题量与备份时一致 |
